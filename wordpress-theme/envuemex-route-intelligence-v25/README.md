# EnVueMex Route Intelligence Theme

## Installation

Upload `envuemex-route-intelligence-v20.zip` from **Appearance > Themes > Add New > Upload Theme**, then activate **EnVueMex Route Intelligence 2.0** on the existing `envuemex.com` WordPress installation. This build uses a fresh v20 theme folder so WordPress does not silently keep the older uploaded copy active.

This theme is designed for the existing EnVueMex database. Activating it preserves and redesigns the site's current published content, including:

- Homepage, Servicios, GPS, Dash Cams, Activos no Vehiculares, Acerca De Nosotros, Contacto, FAQ, Blog and Eventos pages.
- Privacy and Terms pages.
- Published blog articles, category/tag archives and event archives.

The live sitemap reviewed on May 27, 2026 contained 20 sitemap-listed pages and 120 sitemap-listed posts. Old theme/demo sitemap entries are not promoted in the new navigation, but remain accessible in WordPress unless manually removed by an administrator.

## Design Direction

The theme combines the strongest approved mockup elements:

- `Route Intelligence`: photographic hero, premium route-led atmosphere and concise positioning.
- `Control Tower`: operational feedback, live route state and conversion-focused tooling.
- `Fleet Journal`: readable interior pages and corporate credibility.

## Interactive Features

- Live operational indicator strip.
- Prominent three-image hero gallery slider with photographic cards, active progress, manual controls, pause behavior and reduced-motion support.
- Brighter homepage hero using Mexican-flag green as the primary accent.
- The old overlapping live-operation console has been fully removed from markup, CSS and JavaScript.
- Added image-led homepage content sections for connected operations and proof points.
- Spanish-first / English toggle in the header for theme-rendered content.
- Tabbed solution storytelling for GPS, cameras, assets and implementation.
- Fleet savings estimator.
- Dash-cam safety incident/coaching simulator.
- Four-stage implementation roadmap explorer.
- Persistent EnVue assistant for GPS, safety, ROI and demo questions.
- Responsive solution/resource dropdown navigation and mobile menu.

## Elementor

Managed service and sector pages render the clean theme-designed content on the front end so legacy page-builder markup does not duplicate headers, footers, or old layouts. To construct or redesign a page fully in Elementor, assign the **EnVueMex - Elementor Full Canvas** page template.

The homepage design is implemented in `front-page.php`. Blog posts, categories, tags, events and future custom archives render dynamically through `single.php`, `home.php` and `archive.php`.

Dedicated page templates are included for Servicios, GPS, Dash Cams, Activos, Nosotros, Contacto, FAQ and the four sector pages. These templates add designed, bilingual content blocks before the editable WordPress/Elementor body.

## Assets

The logo follows the active EnVueMex staging branding. New fleet photography is included for the route-led homepage hero, control tower, fleet operations, GPS, dash cams, non-vehicle assets and the EnVueMex team presentation.
