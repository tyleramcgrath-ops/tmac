Requires at least: 6.4
Requires PHP: 7.4
License: GPLv2 or later

"The Daily Current" storefront theme for DRIP Clothing Company (WooCommerce).

== Install ==
1. Appearance → Themes → Add New → Upload Theme → choose drip-current.zip → Install → Activate.
2. Settings → Reading: set "Your homepage displays" to a static page (any page works; the theme draws the homepage itself).

== Customize (Appearance → Customize → DRIP Homepage) ==
* Hero — The Daily Current: photo, title, button text/link.
* The Graphic Tee Edit: product IDs (defaults to 6977, 6976, 7141 — Silver Ribbon, Shoreline Minimal,
  Tide Lines). If none are found it shows the newest products in the "tees" category. Each card can
  take an optional override image (a light flat-lay matches the mockup best).
* Between Tides and Traffic: background photo, title, text, optional link.
* Find Your Line: background photo, title, button.
* Footer & social: Instagram / TikTok / YouTube / Facebook URLs (icons only appear once a URL is set),
  region label (defaults to the store country / currency, e.g. "US / USD").
* Site Identity: tick "Use the uploaded logo" to swap the drop + DRIP wordmark for your logo image.

== Menus (Appearance → Menus) ==
* Header menu — until assigned, shows Shop ▾ / Tees / Collections ▾ / Our Story built from your
  WooCommerce categories.
* Footer menu — until assigned, shows Shop / Tees / Collections / Our Story / Journal / Support.
  "Our Story" links to /our-story/, "Support" to /help/ (or /contact/), "Journal" to the posts page.

== WooCommerce ==
Shop, category, product, cart, checkout (block and classic) and My Account pages are styled to match.
Every product grid uses the same card as the homepage. The header bag count updates after add to cart.
