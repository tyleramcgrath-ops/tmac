=== Girls Around the Globe ===
Requires at least: 6.2
Tested up to: 6.8
Requires PHP: 7.4
License: GPLv2 or later

Serious dating, worldwide. A dark, champagne-gold theme with an interactive homepage.

== Install ==

1. In WordPress, go to Appearance > Themes > Add New > Upload Theme.
2. Choose girls-around-the-globe.zip, click Install Now, then Activate.
3. Settings > Reading: "Your homepage displays" can stay on "Your latest posts";
   the theme's homepage shows either way. To keep a blog, set a static front page
   and choose a Posts page.
4. Settings > Permalinks: choose "Post name" for clean page links.

== What's on the homepage ==

* Hero with an "I'm looking for" picker (relationship / marriage & family / dating)
* Swipe demo: drag or tap, with an "It's mutual" match moment
* City explorer with live local times in eight Latin American cities
* How it works, Globe+, FAQ, and a sign-up form

Demo profiles and hero photos are free-licence photos of models and are labelled
as illustrative on the page. Replace them in assets/img/ with your own photos
(keep the same file names), ideally from a shoot you own.

== Settings ==

Appearance > Customize > Girls Around the Globe:

* Join link: leave empty to use the sign-up form on the homepage. Sign-ups are
  saved privately under "Sign-ups" in the admin, with a CSV download button.
  Once the dating app is live, paste its sign-up page here and every "Join"
  button goes there instead (the picker adds ?looking=… to the link).
* Log in link: shows a "Log in" link in the header when set.
* Globe+ price: shown in the Globe+ section.

Appearance > Menus: assign a "Header menu" and "Footer menu" to replace the
default links (Try it, Cities, How it works, FAQ).

Appearance > Customize > Site Identity: upload a logo to replace the bundled
GAG mark in the header, and set the Site Icon (the theme ships a fallback icon).
