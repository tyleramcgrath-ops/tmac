# Brief for Claude in Chrome — posting the McGrath Marketing Group kit

Paste this whole file into a Claude in Chrome conversation, attach or point it at
this folder, and it has everything it needs. Written to be read by the browser
agent, not by a person — but a person can follow it just as well.

---

## What you are doing

Publishing a set of prepared Instagram posts for **McGrath Marketing Group**
(Jupiter, Florida) to the account the human is already signed into.

Every image is already built at the right size. Every caption, alt text and
hashtag block is already written. **Your job is to upload and publish them
exactly as supplied — not to write, improve, shorten or re-tone anything.**

The two files that matter:

- `CAPTIONS.md` — the captions, alt text and first comments, in posting order
- `media/<post-id>/01.jpg, 02.jpg …` — the images, numbered in upload order

---

## Rules, in priority order

1. **Do not change the copy.** Captions and alt text are pasted verbatim,
   including line breaks. If a caption looks wrong to you, stop and say so
   rather than fixing it. The wording is deliberate and has been checked against
   what the business can actually claim.
2. **Never invent a claim.** Do not add a statistic, a price, a timeframe, a
   client name, a guarantee, a result or an award to any post, comment or reply,
   in any circumstance. If something seems to be missing, it is missing on
   purpose.
3. **One post at a time.** Publish a single post, confirm it is live, then stop
   and report before starting the next one — unless the human has told you in
   this conversation to run a batch straight through.
4. **Show the human the review screen before you hit Share.** Caption in the
   box, images in the right order, alt text set. Get a yes.
5. **Stop and ask if you hit a login, a two-factor prompt, a security checkpoint,
   a captcha, or anything that looks like an account warning.** Do not attempt to
   work around any of them.
6. **Do not touch anything else on the account.** No following, unfollowing,
   liking, DMing, replying to comments, editing old posts, or changing settings
   that this brief does not name.
7. **If a step does not match what you see on screen, say so and stop.**
   Instagram changes its interface often. The steps below describe the flow as
   it has worked recently, not a contract. Trust the screen over this file, and
   tell the human what is actually there.

## Publishing a post

Work from `CAPTIONS.md`, in the numbered order, starting at post 1.

**1. Open the composer.** On `instagram.com`, find the create control — a plus
icon in the left navigation, usually labelled *Create*. Choose the option for a
feed post. You should land on a file picker, with wording along the lines of
*Select from computer*.

**2. Choose the images.** Select every file for that post, in one go, in
numerical order: `01.jpg`, then `02.jpg`, and so on. Order matters for a
carousel — slide 1 is the one that stops the scroll, and the last is the closer.
If the picker reorders them, fix it before moving on.

**3. Keep the crop as-is.** Every image is already 1080 × 1350, the exact
portrait ratio Instagram supports. If a crop or zoom control appears, set it to
the original or the 4:5 option so nothing is trimmed. **Do not let it
centre-crop to a square** — that cuts the headline off the bottom of the frame.

**4. Skip filters.** Continue past any filter or editing step without applying
anything. These are brand images; a filter breaks the palette.

**5. Paste the caption.** Copy the caption from the fenced block in
`CAPTIONS.md` and paste it whole. Keep the blank lines between paragraphs —
they are what makes the post readable in the feed. Do not add hashtags here;
they go in the first comment.

**6. Set the alt text.** Look for an accessibility section on the final screen —
usually collapsed, under a heading like *Accessibility*, with a field described
as *Write alt text*. Set the alt text for each image in turn, matching the
numbering in `CAPTIONS.md`. On a carousel you may need to move between slides to
reach each field.

This step is not optional. It is what people using a screen reader get, and it
is also read by the systems this business is trying to be found in.

**7. Review, then share.** Show the human the final screen. On their yes, share
it.

**8. Post the first comment.** Once the post is live, open it and add the
hashtag block from `CAPTIONS.md` as the first comment. Hashtags live here rather
than in the caption so the caption reads as writing rather than as bait.

**9. Report.** Tell the human which post went up, the link to it, and what is
next in the queue.

## Scheduling

**You cannot schedule from `instagram.com`.** The web composer publishes
immediately. Anyone who tells you otherwise is describing a different product.

Two honest options:

- **Publish manually**, one post at a time, on the days in `CALENDAR.md`. This is
  what this brief assumes.
- **Schedule through Meta Business Suite** (`business.facebook.com`) if the
  Instagram account is connected to a Facebook Page. Its planner does support
  scheduling, with its own composer: upload the same files, paste the same
  caption, set the date. Alt text and the first comment may have to be added
  after the post goes live. Only go this route if the human asks for it, and
  check the account is actually connected before promising anything.

Do not install a third-party scheduling tool, connect any service, or enter
credentials anywhere to make scheduling work.

## If something goes wrong

| What you see | What to do |
|---|---|
| Login, 2FA or a security checkpoint | Stop. Hand it to the human. Never attempt a workaround. |
| Upload fails or hangs | Retry once. If it fails again, stop and report — do not try a different file or format. |
| The composer rejects an image size | Stop and report. Do not re-crop. The files are correct; something else is wrong. |
| An action-blocked or rate-limit warning | Stop entirely and tell the human. Do not keep posting. Posting several items in quick succession is a common trigger. |
| The caption pastes with the line breaks collapsed | Fix the line breaks to match `CAPTIONS.md`, then continue. |
| A step here does not match the screen | Describe what you actually see and stop. Do not guess your way through. |

## Profile setup

Only if the human asks. The last section of `CAPTIONS.md` has the exact values:
profile picture, name field, bio, link, category, contact buttons, and the five
highlight covers.

The bio contains line breaks. Instagram's web bio field accepts them, but some
views collapse them — check it looks right after saving.

Highlights can only be built from stories that have already been posted, so that
step waits until the relevant posts exist and have been shared to stories.

## The one thing to remember

Everything in this kit was written to be defensible: nothing claims a result the
business cannot stand behind. The quickest way to break that is to improve the
copy on the way past. Paste it as written.
