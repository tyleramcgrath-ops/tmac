Sign in to vote

Under the proposed system, your state election office mails a single-use Voter Access Code to the address on your voter registration. For this demonstration, generate a practice code.

Why the system does not ask for a Social Security number. SSNs have been exposed in large data breaches, so knowing one does not prove who you are. The production system would confirm identity against state voter rolls, a code mailed to your registered address, and a government photo ID. It would not store Social Security numbers.

Verifying eligibility

In this demonstration these checks are simulated. In production, each is performed by a separate service.

  • Access code is valid and has not been used
  • Registered voter in your state
  • Citizenship confirmed through voter registration record
  • Photo ID matched to the registered voter
  • Encrypted session established

System design

Four requirements the production system must meet before it is used in any real election.

1

Eligible citizens only

Every voter is matched to an official state voter roll, which already requires proof of citizenship, plus a mailed access code and photo ID. A person who is not on the roll cannot receive a ballot.

2

One ballot per voter

Access codes are single-use. Once a ballot is submitted, the voter is marked as having voted, and duplicate ballots by mail or in person are rejected.

3

Secret ballot

Identity and selections are separated before storage. The voter roll records only that a person voted. The tally records only the selections. No record links the two.

4

Independently verifiable

Each ballot produces a receipt listed in a public ledger. Results can be recounted by anyone, and every ballot has a paper record for post-election audits.

Development plan

Election systems must earn public trust. Each phase is completed and reviewed publicly before the next begins.

  1. Complete

    Working demonstration

    The full voter process, receipts and results, available on this page.

  2. Phase 1

    Secure build and independent audit

    Production encryption and identity verification, reviewed by an outside security firm. Source code published for public inspection.

  3. Phase 2

    Private-organization elections

    Live use by unions, associations, student governments and nonprofits, where online voting is already permitted.

  4. Phase 3

    Accessibility pilots

    Work with election officials to serve overseas military voters and voters with disabilities.

  5. Phase 4

    State certification

    Pursue testing and certification against federal voting system guidelines, one jurisdiction at a time.

Frequently asked questions

Is this a real election?

No. This is a demonstration with fictional candidates. Your demonstration ballot is stored only in your browser, and the results shown are simulated.

Can I use Homeballot to vote in an actual election?

Not at this time. Please vote using the methods your state provides: in person, by mail or absentee. Homeballot is not affiliated with any government agency or election office.

Is online voting secure?

Security researchers have raised serious concerns about online voting, and those concerns shape this plan. The system will be open source, independently audited, backed by a paper record for every ballot, and used first in lower-stakes elections before any public election.

How are non-citizens and fraudulent accounts prevented?

Only people listed on an official state voter roll can vote, and registration already requires citizenship. Voters must also have the single-use code mailed to their registered address and pass a photo ID check.

How will contributions be used?

Funds go to development and independent security review, in the order of the milestones above. Progress reports will be published as each milestone is reached.
