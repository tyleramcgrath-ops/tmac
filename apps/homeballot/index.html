Sign in to vote

In the real system your state election office mails a one-time Voter Access Code to the address on the voter roll, after it has already confirmed you are a U.S. citizen. For the demo, grab a practice code.

Why not just type your Social Security number? SSNs have leaked in huge breaches, so anyone could type yours. The full build checks identity against state voter rolls plus a photo-ID and face match, and never stores your SSN.

What we'd build

Four promises the real system has to keep

🇺🇸

Only eligible Americans

Identity is checked against official state voter rolls, which already confirm citizenship, plus photo ID and a live face match. No roll record, no ballot.

☝️

One person, one vote

Each voter gets a single-use code. Once a ballot is cast the code is burned, and any in-person or mail ballot for the same voter is blocked.

🤫

Your vote stays secret

Your identity and your choices are split apart before the ballot is stored. The count sees choices, the roll sees "voted", and nothing joins the two.

🧾

Proof it was counted

Every ballot gets a receipt code in a public ledger. Anyone can recount it, and every electronic ballot has a paper record for audits.

The plan

From demo to real elections, one step at a time

Public elections have to earn trust. So we start small, get audited in the open, and only move up once each stage holds.

  1. Now

    Working demo

    The prototype you just used: the full voter flow, receipts and a live tally.

  2. Phase 1

    Secure build + open audit

    Real encryption, identity checks and an independent security audit. Source code published for anyone to inspect.

  3. Phase 2

    Private elections

    Run real votes for unions, HOAs, student governments and nonprofits, where online voting is already allowed.

  4. Phase 3

    Accessibility pilots

    Partner with election offices on the voters who need it most: overseas military and voters with disabilities.

  5. Phase 4

    State partnerships

    Work with states and certification bodies to meet federal voting system standards, one jurisdiction at a time.

Straight answers

Is this a real election?

No. It's a simulated election with made-up candidates so you can see how the experience would feel. Your demo vote is saved only in your own browser, and the tally is a demo.

Can I use this to vote in an actual election?

Not yet. Vote the way your state allows today: in person, by mail, or absentee. Homeballot is not affiliated with any government or election office.

Isn't online voting risky?

It can be, and security experts have real concerns. That's exactly why the plan starts with open source code, independent audits, a paper record for every ballot, and low-stakes elections first. We'd rather move slowly than lose anyone's trust.

How do you stop non-citizens or fake accounts?

You can only vote if you're on your state's official voter roll, which already requires citizenship. On top of that: a one-time code mailed to your registered address, photo ID and a face match.

What happens to the money?

It goes to building and auditing the secure system in the order shown above. We'll post progress updates publicly as each phase is reached.
