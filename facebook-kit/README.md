# Facebook kit — McGrath Marketing Group

Twelve posts for the Page, the Page setup itself, and the brief that hands it
all to Claude in Chrome.

## Give it to Claude in Chrome

Open a Claude in Chrome conversation with Facebook signed in and say:

> Follow `BRIEF-FOR-CLAUDE-BROWSER.md` in this folder. Set the Page up first,
> then publish post 1.

That file carries the procedure and the guardrails. Everything else is what it
reads from.

## What is in the folder

| | |
|---|---|
| `BRIEF-FOR-CLAUDE-BROWSER.md` | The operator brief. This is the file you hand over. |
| `CAPTIONS.md` | Captions, links, alt text and every Page field. Generated. |
| `CALENDAR.md` | What to post when, and why that order. |
| `media/<post-id>/` | Feed images, 1080 × 1350. |
| `media/page/` | Cover photo (1640 × 856) and profile picture. |
| `media/share/` | Link-preview cards, 1200 × 630, one per page. |
| `posts.json` | The source. Edit here, not in `CAPTIONS.md`. |
| `build.py` | Rebuilds `media/` and `CAPTIONS.md` from `posts.json`. |

## This is not the Instagram kit with the names changed

Facebook differs in four ways that changed the writing, not just the sizes:

**Links work.** Four of the twelve are link posts pointing at a service page.
Nothing says "link in bio", because nothing has to.

**Hashtags barely function here.** Each post carries two or three, or none,
rather than Instagram's twenty-tag block — and they go at the end of the
caption, not in a comment.

**Carousels read worse than long captions.** Instagram's three carousels are
folded into caption text. Facebook rewards a post that can be read where it
sits.

**The feed truncates at roughly 400 characters** behind a *See more*, so every
caption is built to work from its first two lines.

## A theme change shipped with this

**Your link previews were likely coming up without a picture.**

`mcg_social_tags()` built `og:image` by checking file extensions in the order
`webp, jpg, png` — and every page photograph is a WebP, so every share pointed
at one. WebP support across the social crawlers is inconsistent, and a preview
that silently loses its image is a weak post every time you or anyone else
shares a page.

Three changes, in `themes/mcgrath-chrome/functions.php`:

- A new `share-<key>.jpg` is preferred first — a 1200 × 630 JPEG built for this,
  which is the size Facebook and LinkedIn render as a large card. Those six
  files are now in `themes/mcgrath-chrome/assets/img/`, generated by this kit's
  `build.py` and also kept in `media/share/`.
- Failing that, JPEG and PNG are now checked **before** WebP. WebP stays last so
  a page with nothing else still gets a tag rather than none.
- `og:image:width`, `og:image:height` and `og:image:alt` are now emitted, so a
  crawler can lay the card out on the first pass instead of showing a small
  preview until it has fetched and measured the file.

Theme version is 2.6.0, in both `style.css` and `functions.php`.

**One caveat that has not changed:** these tags stand down when Yoast, Rank
Math, AIOSEO, SEOPress or Slim SEO is active, because those plugins publish
their own. If you run one, set its social image per page to the matching
`share-*.jpg` or the previews stay as the plugin has them.

**Already shared a link?** Facebook caches what it scraped. Paste the URL into
`developers.facebook.com/tools/debug/` and use *Scrape Again* to refresh it.

## What the copy will and will not say

Same rule as the site and the Instagram kit: **no price, no timeframe, no
statistic, no client name, no certification, no award, no guarantee.** Every
claim traces to a line already published on mcgrathmarketinggroup.com.

Post 11 exists to say plainly that nobody can guarantee what an AI model
recommends.

## Two Page fields need a decision from you

`posts.json` flags both, and the brief tells the agent to ask rather than pick:

**Address.** Set a service area rather than a street address if you do not take
visitors. A Page showing an address nobody can visit is worse than one showing
none.

**Hours.** Only set them if you will answer during them. "Always open" on a
one-person business reads as untrue the first time nobody picks up.

## Changing anything

```bash
cd facebook-kit
python3 build.py
```

Rewrites `media/` and `CAPTIONS.md` together, so pictures and words cannot drift
apart. Needs Python 3 and Pillow (`pip install pillow`); the three fonts are
fetched once into `.fonts/` and are not committed.

If you change a `share_cards` entry, copy the rebuilt file into
`themes/mcgrath-chrome/assets/img/` as `share-<key>.jpg` so the site serves the
new one.
